The method

Reverse engineering & taxonomy

No source code was given — only a bitstream, an interface doc, and block diagrams. Here's how the key fell out, and where this Trojan sits in the standard classification.

Rebuild the datapath. The diagrams show a 32-bit SPI shift register, two crypto cores, and a round-controller FSM. Reconstructed in clean Verilog.
Guess the round structure. AES byte-substitution + an 8-bit rotation + a per-round key XOR — a small space of orderings.
Brute-force the key. For each candidate, test all 2³² keys against 0x59C359C3 → 0x9CD84392. One fits uniquely: K = 0x8E043CB1 — matching the value in the provided diagrams.
Insert WhisperKey. An AI-driven pipeline grafts the trigger comparator + key-leak mux into the output path, then proves stealth and the exploit in simulation.
